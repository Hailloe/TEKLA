⚙️ 设置

所有 API Key 只保存在这台设备的浏览器里，只发送给对应的服务。换电脑或清除浏览器数据后需要重新填写。

AI 翻译 · Claude（顶部翻译引擎选「Claude AI 翻译」时使用）

在 Anthropic Console 申请 Key。

AI 翻译 · DeepSeek / 其他 AI（顶部选「DeepSeek / 其他 AI」时使用）

默认是 DeepSeek（在 platform.deepseek.com 申请 Key）。 通义千问、Kimi 等支持 OpenAI 接口格式的 AI，改成它们的接口地址和模型名即可。

语音识别（把声音变成文字）

默认是国内的硅基流动 SenseVoice（在 cloud.siliconflow.cn 申请 Key），不需要连 Google。 也可以用 OpenAI：接口地址 https://api.openai.com/v1，模型 whisper-1。 AI 识别是一句话说完后整句识别，比浏览器自带的慢 1–3 秒，但口音、专业词更准；同时听「我 + 对方」时能分清是谁说的，也能识别你说的中文。
点击下方 开始翻译，允许使用麦克风。
开会、看电视、看视频都可以：把手机/电脑放在能听清声音的位置即可。
推荐使用 Chrome / Edge（电脑、安卓）或 Safari（iPhone）。
